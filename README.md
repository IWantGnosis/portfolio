# My 3D Portfolio

A static portfolio with a Three.js 3D background. No build step needed.

## Run locally
Open index.html in a browser, or run a local server:

    npx serve .

## Customize
- Replace "Your Name", "YN", and the email in index.html.
- Edit the project cards in index.html.
- Change colors in the :root block of style.css.

## Deploy
- GitHub Pages: push to GitHub, then Settings > Pages > Deploy from branch > main / root.
- Vercel: import the repo at vercel.com/new. Framework preset: Other. No build command, output directory empty.
